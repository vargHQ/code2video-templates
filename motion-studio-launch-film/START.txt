MOTION STUDIO / OPUS 5.5

An original eight-file motion-production workflow for Opus 5.5, built
around official Remotion and Claude Code guidance.

1. Use a local Remotion project with Node.js and Claude Code installed.
   For a new project, run the current official setup:

   npx create-video --yes --blank motion-studio
   cd motion-studio
   npx remotion skills add

   Select Claude Code in the skills installer. Install the project dependencies
   if your scaffold asks. Keep compatible package versions together.

2. Extract these eight .md files into the project root, beside its package.json.
   If CLAUDE.md or any named file already exists, preserve it and merge the
   relevant guidance deliberately. Do not blindly overwrite existing rules.
   These files do not auto-install a plugin. CLAUDE.md directs the agent to
   read the other files at the relevant stage.

3. Put your product images, logo, fonts, and permitted audio under public/.
   Supply the target viewer, product action, and closing destination.
   The filenames and actual available states must be recorded in ASSETS.md.

4. In the project folder start:

   claude --model claude-opus-5-5

   Use a current Claude Code version and a provider/account offering this
   exact model. Do not assume that an opus alias resolves identically on
   every provider. Normal model usage and software license terms apply.

5. Paste LAUNCH-PROMPT.txt, then append your product brief and asset paths.
   Alternatively: Read CLAUDE.md and BRIEF.md. Build the film using these
   eight files and the supplied assets. Finish with the rendered outputs.

6. Preview in a second terminal inside the same project:

   npm run dev

   The default harness asks for a 20-second, 1920x1080, 60fps film. Change the
   brief if your destination needs another canvas or duration.
